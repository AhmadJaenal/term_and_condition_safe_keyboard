1Ruang Lingkup

Kebijakan Privasi ini menjelaskan bagaimana Safe Keyboard (Aplikasi) memperlakukan data Anda saat menggunakan aplikasi keyboard Android yang mendeteksi dan memblokir kata kasar, pornografi, dan judi online (judol), serta fitur berita dan pengelolaan langganan yang menyertainya. Kebijakan ini berlaku untuk seluruh pengguna Aplikasi dan merupakan satu kesatuan dengan Syarat & Ketentuan Aplikasi.

2Cara Aplikasi Memproses Ketikan

Safe Keyboard berjalan sebagai Input Method Editor (IME) di perangkat Anda. Seluruh proses pencocokan kata terhadap kamus deteksi dan daftar kata kustom milik Anda dilakukan sepenuhnya secara lokal, di perangkat Anda. Tidak ada isi ketikan (termasuk pesan, kata sandi, maupun data lain yang Anda ketik) yang dikirim, diunggah, atau disimpan ke server kami dalam bentuk apa pun.

3Data yang Kami Kumpulkan

Data Akun

  • Nama dan alamat email, untuk keperluan registrasi akun.
  • ID pengguna yang dibuat oleh sistem.
  • Status dan riwayat langganan (tier aktif, tanggal berakhir, histori transaksi).
  • Tanggal lahir, untuk keperluan verifikasi umur pengguna.

Data Penggunaan (Anonim/Agregat)

  • Statistik penggunaan fitur, tanpa isi ketikan.
  • Informasi perangkat (tipe OS, versi Android).
  • Log crash dan error, untuk keperluan perbaikan Aplikasi (dikumpulkan melalui Firebase Crashlytics, lihat Bagian 10).
  • Perkiraan lokasi negara/wilayah, diperoleh secara otomatis dari alamat IP melalui Firebase Analytics untuk keperluan statistik agregat bukan lokasi presisi/GPS, dan tidak digunakan untuk melacak pergerakan Anda.

4Data yang Tidak Kami Kumpulkan

Untuk menjaga kepercayaan Anda, hal-hal berikut tidak pernah kami kumpulkan, kirim, atau simpan di server:

  • Konten yang Anda ketikkan (pesan, catatan, dan sejenisnya).
  • Pesan pribadi atau isi komunikasi Anda dalam aplikasi lain.
  • Kata sandi atau data finansial Anda.
  • Lokasi presisi/GPS perangkat Anda.
  • Daftar Kata Kustom yang Anda tambahkan (tersimpan dan diproses seluruhnya secara lokal di perangkat Anda, tidak disinkronkan ke server kami).
  • PIN Keamanan (Kunci Orang Tua) yang Anda buat tersimpan dalam bentuk terenkripsi/di-hash secara lokal di perangkat Anda, tidak pernah dikirim atau disimpan di server kami. Lihat Bagian 12 untuk penjelasan lengkap.

5Retensi & Penghapusan Data

  • Data akun Anda (nama, email, ID pengguna, status langganan, histori transaksi) disimpan selama akun Anda masih aktif digunakan.
  • Ketika Anda meminta penghapusan akun, seluruh data akun yang tersimpan di server kami dihapus secara permanen dan tidak dapat dipulihkan kembali.
  • Daftar Kata Kustom tersimpan lokal di perangkat Anda dan tidak terpengaruh oleh penghapusan akun; data tersebut hanya hilang jika Aplikasi di-uninstall atau datanya dibersihkan manual dari perangkat.
Penghapusan akun bersifat final. Pertimbangkan keputusan ini dengan saksama sebelum mengajukan permintaan.

7Hak Anda sebagai Subjek Data

Sesuai Undang-Undang No. 27 Tahun 2022 tentang Pelindungan Data Pribadi, Anda berhak untuk:

  • Mengakses data pribadi yang kami simpan terkait akun Anda.
  • Memperbaiki data yang tidak akurat atau sudah usang.
  • Menghapus data pribadi Anda melalui penghapusan akun.
  • Menarik persetujuan yang telah Anda berikan sebelumnya.

Untuk menggunakan hak-hak ini, hubungi kami melalui kontak pada Bagian 14.

8Keamanan Data

  • Enkripsi data saat transmisi menggunakan HTTPS/TLS.
  • Penyimpanan data akun pada server yang aman (Supabase).
  • Pembatasan akses data hanya untuk keperluan operasional yang sah.
  • Kami tidak menjual atau membagikan data pribadi Anda kepada pihak ketiga untuk kepentingan komersial.

9Pengguna Anak

Safe Keyboard dirancang untuk membantu melindungi anak dari konten berbahaya, namun bukan pengganti pengawasan orang tua/wali.

Saat pendaftaran akun, Aplikasi meminta tanggal lahir Pengguna untuk memverifikasi usia. Pengguna yang berusia di bawah 13 tahun tidak dapat menyelesaikan proses pendaftaran akun sistem akan menampilkan pemberitahuan bahwa pendaftaran untuk usia tersebut harus dilakukan oleh orang tua/wali menggunakan data mereka sendiri. Tidak ada data pribadi yang dikumpulkan atau disimpan dari percobaan pendaftaran yang gagal karena verifikasi usia ini.

Pengumpulan data statistik penggunaan, log crash, dan diagnostik (melalui Firebase Analytics dan Firebase Crashlytics, lihat Bagian 10) hanya diaktifkan untuk akun yang berstatus aktif dan telah terverifikasi berusia 13 tahun ke atas. Akun yang belum terverifikasi tidak akan mengaktifkan pengumpulan data ini.

Fitur Berita yang membahas topik keamanan digital anak bersifat edukatif untuk orang tua/wali, bukan nasihat hukum, psikologis, maupun pengasuhan.

10Pihak Ketiga

Pembayaran langganan diproses melalui Google Play Billing; kami tidak menerima atau menyimpan data kartu pembayaran Anda. Data akun disimpan pada infrastruktur Supabase sebagai penyedia layanan server kami.

Kami menggunakan Firebase Crashlytics (layanan dari Google) untuk mendeteksi dan melaporkan crash/error Aplikasi secara otomatis. Firebase Crashlytics dapat mengumpulkan Firebase Installation ID, model perangkat, versi sistem operasi, versi Aplikasi, dan detail teknis seputar crash (stack trace) data ini dikirim ke server Google, terpisah dari server kami.

Kami juga menggunakan Firebase Analytics (layanan dari Google) untuk memahami statistik penggunaan fitur secara anonim/agregat. Firebase Analytics dapat mengumpulkan identifier perangkat (App Instance ID), data interaksi dalam Aplikasi (fitur yang digunakan, durasi sesi), dan perkiraan lokasi negara/wilayah berdasarkan alamat IP.

Kami menggunakan Firebase Cloud Messaging (FCM) (layanan dari Google) untuk mengirim notifikasi push ke perangkat Anda, misalnya pemberitahuan pembaruan fitur atau informasi keamanan penting. FCM menggunakan token perangkat (bukan alamat email Anda) untuk mengirimkan notifikasi.

Baik Firebase Crashlytics, Firebase Analytics, maupun Firebase Cloud Messaging tidak mengumpulkan isi ketikan, Kata Kustom, atau PIN Keamanan Anda. Ketiga layanan ini bertindak sebagai penyedia layanan (data processor) bagi kami, bukan pihak ketiga independen yang menggunakan data Anda untuk kepentingan mereka sendiri.

Keempat pihak tersebut (Google Play Billing, Supabase, dan Firebase) memiliki kebijakan privasi masing-masing yang berlaku atas data yang mereka proses.

11Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini sewaktu-waktu. Perubahan signifikan akan diberitahukan melalui notifikasi di dalam Aplikasi sebelum berlaku efektif. Penggunaan Aplikasi secara berkelanjutan setelah perubahan berlaku dianggap sebagai persetujuan Anda terhadap kebijakan yang telah diperbarui.

12PIN Keamanan (Kunci Orang Tua)

Aplikasi menyediakan fitur PIN Keamanan yang dapat Anda buat sendiri untuk mengunci akses ke pengaturan sensitif, meliputi: Level Filter, Kata Terlarang (Kata Kustom), Kamus Bahasa, Pengaturan Keamanan (termasuk proteksi agar Aplikasi tidak dapat dihapus tanpa otorisasi), Setel Ulang Keyboard, Ubah Kata Sandi, dan Riwayat Berlangganan.

  • PIN Keamanan disimpan dalam bentuk terenkripsi/di-hash secara lokal di perangkat Anda dan tidak pernah dikirim, diunggah, atau disimpan di server kami.
  • Jika Anda lupa PIN Keamanan, pemulihan hanya dapat dilakukan melalui verifikasi ulang akun (login dengan email dan kata sandi akun Anda) bukan dengan menyimpan PIN itu sendiri di server.
  • Fitur "Pengaturan Keamanan" dapat meminta izin Device Administrator pada perangkat Android Anda untuk mencegah penghapusan (uninstall) Aplikasi tanpa otorisasi. Izin ini bersifat opsional, hanya aktif atas persetujuan eksplisit Anda, dan dapat dinonaktifkan kapan saja menggunakan PIN Keamanan yang sama.
  • Anda bertanggung jawab penuh menjaga kerahasiaan PIN Keamanan milik Anda.
